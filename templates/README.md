# Templates

Canonical document templates for the Ferret project.

Copy the relevant template, fill in the metadata header, and place the document in the appropriate `docs/` subfolder.

---

## Available Templates

| Template | Use for | Destination |
|---|---|---|
| [adr.md](adr.md) | Architecture Decision Records | `docs/adr/` |
| [spec.md](spec.md) | Sprint and feature specifications | `docs/specs/` |
| [prd.md](prd.md) | Product Requirements Documents | `docs/specs/` |
| [architecture.md](architecture.md) | Architecture design documents | `docs/architecture/` |
| [api.md](api.md) | API endpoint documentation | `docs/api/` |
| [database.md](database.md) | Data model and schema docs | `docs/database/` |
| [plugin.md](plugin.md) | Plugin design documents | `docs/architecture/` |
| [mcp.md](mcp.md) | MCP server / client design | `docs/architecture/` |
| [cli.md](cli.md) | CLI command reference | `docs/api/` |
| [testing.md](testing.md) | Test strategy documents | `docs/specs/` |
| [release.md](release.md) | Release notes | `docs/` (tagged releases) |
| [versioning.md](versioning.md) | Versioning policy | `docs/` |
