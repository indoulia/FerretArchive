# Theme: Collaboration

Multi-user and subscription-based context sharing — consumers acting on shared, current context together rather than each pulling it independently.

## Capabilities This Theme Touches

[Context Delivery](../../FEP/capabilities/FEP-002-CAP-06-Context-Delivery.md), [Access Control & Policy](../../FEP/capabilities/FEP-002-CAP-08-Access-Control-Policy.md)

## Roadmap Items

- **Subscription-Based Context Delivery** — consumers subscribe to be notified when relevant context changes, rather than only pulling on request. Already anticipated structurally by [FEP-001 §6](../../FEP/FEP-001-Product-Architecture.md). See [FERRET-PRODUCT-ROADMAP.md §3](../FERRET-PRODUCT-ROADMAP.md#3-future-capability-evolution).
- **Change-subscription notifications** — Slack/Teams/email delivery of subscribed changes. See [PROPOSALS/](../PROPOSALS/README.md).
- v2.0's 4-role sharing model (Owner/Admin/Developer/Viewer) is the current foundation this theme builds on; the AI-agent role and richer invitation flows are deferred to v3 ([Deferred-Scope.md](../Future/Deferred-Scope.md)).
