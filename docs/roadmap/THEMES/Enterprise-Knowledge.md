# Theme: Enterprise Knowledge

Broader acquisition — new source types, especially enterprise collaboration platforms — so that no engineering-relevant knowledge that exists in an accessible source is invisible to Ferret (FEP-001 Goal G1).

## Capabilities This Theme Touches

[Context Acquisition](../../FEP/capabilities/FEP-002-CAP-02-Context-Acquisition.md), [Extensibility](../../FEP/capabilities/FEP-002-CAP-09-Extensibility.md)

## Roadmap Items

- **Multi-Source Enterprise Acquisition** — Slack/Teams, Confluence, email as source categories. See [FERRET-PRODUCT-ROADMAP.md §3](../FERRET-PRODUCT-ROADMAP.md#3-future-capability-evolution).
- Follow-on Enterprise Content Packs beyond Pack 1 (PDF/DOCX/XLSX, shipped in v0.16.0) — further document formats and structured-data sources.

## Open Question

Where "engineering-relevant source" stops is unresolved ([FEP-001 §9 Q6](../../FEP/FEP-001-Product-Architecture.md)) — this theme's scope grows only as fast as that boundary is defined, to avoid an acquisition surface that outpaces Organization and Assembly's ability to keep up (FEP-001 Risk: Unbounded acquisition surface).
