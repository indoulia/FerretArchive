# Theme: Workspace Experience

New delivery surfaces and consumer-facing ergonomics — broadening who can practically consume Ferret's context without favoring any one consumer's shape of interaction (FEP-001 Principle P4).

## Capabilities This Theme Touches

[Context Delivery](../../FEP/capabilities/FEP-002-CAP-06-Context-Delivery.md)

## Roadmap Items

- **IDE-native delivery surface** — an editor extension (VS Code / JetBrains) surfacing context inline. See [PROPOSALS/](../PROPOSALS/README.md).
- **Web dashboard** — a visual surface alongside the existing CLI/MCP surfaces.
- **Workspace templates** — pre-configured scope/connector bundles for common organizational shapes. See [PROPOSALS/](../PROPOSALS/README.md).

## Guardrail

Every new surface must add reach, not replace an existing one — the CLI and MCP surfaces are not deprecated by adding a dashboard or IDE extension. This mirrors the additive-migration principle already applied to the v2.0 workspace model ([NEXT/V2.md](../NEXT/V2.md)).
