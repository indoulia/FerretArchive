# Product Proposals

Unapproved product ideas. Nothing here is committed — a proposal is a candidate for a future Roadmap generation, not a plan. See the [promotion lifecycle](../README.md#promotion-lifecycle).

## Open Proposals

**Ferret Hub** — a hosted service for cross-organization workspace sharing. Name and shape carried over from `FUTURE-002`'s deferred concept, deliberately decoupled from that document's embedded-AI framing (see the [guardrail note](../README.md#note-on-a-standing-open-question)). Relates to [THEMES/Federation.md](../THEMES/Federation.md) and [FUTURE/V4.md](../Future/V4.md).

**Context Health Dashboard** — a standalone delivery surface exposing freshness, provenance completeness, and coverage gaps. Builds on the Context Health & Trust Surfacing capability. Relates to [FUTURE/V3.md](../Future/V3.md).

**IDE-native delivery surface** — a VS Code / JetBrains extension surfacing context inline in the editor. Relates to [THEMES/Workspace-Experience.md](../THEMES/Workspace-Experience.md).

**Workspace templates** — pre-configured scope/connector bundles for common organizational shapes (a service repo + its shared libraries + its infra repo, for example), reducing time-to-first-reference. Relates to [THEMES/Workspace-Experience.md](../THEMES/Workspace-Experience.md).

**Change-subscription notifications** — Slack/Teams/email delivery when subscribed context changes. Relates to [THEMES/Collaboration.md](../THEMES/Collaboration.md).

## How a Proposal Moves Forward

A proposal is promoted to the Roadmap proper (a `NEXT/` or `FUTURE/` document) only on explicit product approval — not by being written down here. Until then, it stays a candidate.
