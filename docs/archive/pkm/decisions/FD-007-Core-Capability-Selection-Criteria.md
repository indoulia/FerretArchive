## Title

Core Capability Selection Criteria

## Definition

A Core Capability is a capability that provides fundamental business value and serves as a long-term foundation for additional product capabilities.

## Selection Criteria

A Core Capability:

- Delivers identifiable customer value.
- Belongs to exactly one Product Domain.
- Can evolve independently.
- Can be extended by future capabilities.
- Is expected to remain relevant long-term.

A Core Capability is NOT:

- A UI screen.
- A technology.
- A microservice.
- A temporary feature.
- An implementation detail.

## Governance

- Only Core Capabilities are included in the PKM Capability Catalog.
- Supporting implementation details are documented elsewhere.
- New Core Capabilities require ARB approval.
