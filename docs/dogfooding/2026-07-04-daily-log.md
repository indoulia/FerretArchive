## Session update — real bug found and fixed on a large external repo

Dogfooded against a real ~27k-file external codebase (not this repo; kept generic per confidentiality — no filenames or content from it appear here). Read-only: no commits made to that repo, only a local `.ferret/` workspace cache.

- `ferret index` ran ~6309s (~105 min) wall clock before exiting 1. **Not treated as a valid throughput baseline** — the run hit errors throughout (see below), so this number reflects a degraded run, not clean indexing speed. A trustworthy throughput figure needs a clean re-run once the fixes below are released.
- Failures were two distinct issues:
  1. Directory-open failures — the same already-tracked release-lag issue (#13, fix already on `main`, not yet in a published npm build).
  2. **New bug found:** paths containing a space resolved with a literal `%20` in place of the space (e.g. a real `Deploy_prsingh 20260601T195547_32344` directory resolved to the nonexistent `Deploy_prsingh%2020260601T195547_32344`). Root cause: `filesystem://` is a custom URI scheme, so `Uri.AbsolutePath` doesn't auto-decode percent-encoding the way it would for `file://`'s `.LocalPath`. Three call sites read `AbsolutePath` directly and used it as a literal path with no unescaping (`FilesystemConnector.cs:81`, `FerretIgnoreProvider.cs:34`, `GitIgnoreProvider.cs:36`).
  - Filed as [GitHub issue #14](https://github.com/indoulia/Ferret/issues/14).
  - **Fixed via TDD** on the `dogfooding` branch (commit `ee01910`): added `OpenAsync_Returns_Stream_For_FileName_With_Space`, confirmed it failed with the exact `%20` artifact (red), wrapped all three `AbsolutePath` reads with `Uri.UnescapeDataString(...)` (green). Full solution suite still 0 failures after the fix.
  - **Committed, not pushed** — per current instruction to keep this branch commit-only pending review. Not re-validated live against the external repo, since that would require a source build, which would break DOGFOOD-001's npm-only distribution evidence rule; will validate once released.
