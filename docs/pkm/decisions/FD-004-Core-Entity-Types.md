## Title

Core PKM Entity Types

## Definition

Core Entity Types are the primary business objects that make up the Product Knowledge Model.

## Approved Entity Types

| ID | Entity | Purpose |
|----|--------|---------|
| ENT-001 | Product Principle | Long-lived architectural guidance |
| ENT-002 | Product Domain | Groups related capabilities |
| ENT-003 | Capability | A business capability provided by Ferret |
| ENT-004 | Technology | Technology used or integrated by Ferret |
| ENT-005 | Relationship | Connects two PKM entities |
| ENT-006 | Architecture Decision | Records significant architectural decisions |

## Governance

- Entity IDs use ENT-xxx.
- Every entity has a unique identifier.
- New entity types require explicit ARB approval.
- PKM v0.1 contains exactly these six entity types.
