## Conventions

- Schemas are documented using the template in [/templates/database.md](../../templates/database.md).
- Entity-relationship diagrams use [Mermaid](https://mermaid.js.org/) `erDiagram` syntax.
- All schema changes must be delivered as migrations (no manual DDL in production).
- Column naming: `snake_case`. Table naming: `snake_case`, plural.
