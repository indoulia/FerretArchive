## Conventions

- All REST APIs follow the [Ferret API Style Guide](../guides/api-style-guide.md) (to be written).
- Endpoints are versioned: `/api/v1/…`
- All responses use `application/json`.
- Authentication: Bearer token (JWT) or API key header.
- Errors follow [RFC 9457 Problem Details](https://www.rfc-editor.org/rfc/rfc9457).
