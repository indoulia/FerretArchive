# Ferret v0.15.0 — Distribution Platform

The first release you can install without a .NET SDK, a source checkout, or a developer environment.

```bash
npm install -g @indoulia/ferret
ferret --version
```

## Highlights

- **GitHub Releases are the single source of truth.** Every distribution channel consumes published release assets through a stable, versioned `release-manifest.json` contract — no second build, no filename guessing.
- **NPM is the first consumer.** `@indoulia/ferret` downloads the self-contained binary for your platform, verifies its SHA256, and installs it atomically. One runtime dependency (`extract-zip`); everything else is the Node standard library.
- **Checksum-verified, atomic installs.** Downloads are verified against the manifest's SHA256 (hard-fail on mismatch) and swapped into place so a failed install never destroys a working one.
- **Your data is never touched on uninstall.** `npm uninstall -g @indoulia/ferret` removes only the binary; `.ferret` workspaces, indexes, and configuration are left intact.

## Install / Upgrade / Uninstall

| Action | Command |
|---|---|
| Install | `npm install -g @indoulia/ferret` |
| Upgrade | `npm update -g @indoulia/ferret` |
| Uninstall | `npm uninstall -g @indoulia/ferret` |

Install locations: Windows `%LOCALAPPDATA%\Programs\Ferret` · macOS `~/Library/Application Support/Ferret` · Linux `~/.local/share/ferret`.

## Assets in this release

- `Ferret-0.15.0-win-x64.zip`, `Ferret-0.15.0-linux-x64.zip`, `Ferret-0.15.0-osx-arm64.zip`, `Ferret-0.15.0-osx-x64.zip` — self-contained, single-file binaries.
- `SHA256SUMS.txt` — checksums for all archives.
- `release-manifest.json` — the machine-readable distribution contract (`schemaVersion: 1`).
- `*.nupkg` — NuGet packages (unchanged).

Verify a download manually:

```bash
sha256sum -c SHA256SUMS.txt
```

## For maintainers of other channels

Read `release-manifest.json` to resolve assets — do not infer filenames or scrape the release page. The same contract is reserved for future consumers (Homebrew, winget, Chocolatey, Scoop, an enterprise mirror, and `ferret self-update`).

## Known limitations

- **macOS binaries are unsigned and unnotarized.** macOS users will see a Gatekeeper prompt; allow the binary in System Settings → Privacy & Security. Signing is deferred to a future milestone.

## Maintainer prerequisites (one-time, before publishing)

- Create the `@indoulia` npm scope on npmjs.com.
- Add an npm automation token as the `NPM_TOKEN` repository secret (Settings → Secrets and variables → Actions); `npm-publish.yml` needs it.

## Release procedure

1. Merge the Distribution Platform PR into `main`.
2. Tag `v0.15.0` on the merge commit and push the tag.
3. `release.yml` builds the per-RID zips, `SHA256SUMS.txt`, and `release-manifest.json`, and creates a **draft** GitHub Release with them attached.
4. Review the draft, then publish it.
5. Publishing fires `npm-publish.yml`, which publishes `@indoulia/ferret@0.15.0`.
