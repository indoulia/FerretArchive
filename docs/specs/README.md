## Spec Lifecycle

```
Draft → Review → Approved → In Development → Done
```

A spec must reach **Approved** status before implementation begins.

---

## Writing a Spec

Use the template in [/templates/spec.md](../../templates/spec.md).

Each spec must include:
- Problem statement and motivation
- Scope (in / out)
- Acceptance criteria
- Open questions
