---

## Writing a New Example

1. Create a new folder under `examples/`.
2. Add a `README.md` explaining what the example demonstrates.
3. Keep the example minimal — its purpose is illustration, not production use.
4. Examples must not reference internal NuGet feeds; use only publicly published packages.
